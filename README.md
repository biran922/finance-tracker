# מעקב הוצאות

אפליקציית ווב אישית למעקב הוצאות, בעברית.

- כל הנתונים נשמרים **במכשיר בלבד** (IndexedDB), מוצפנים ב-AES-GCM במפתח שנגזר מקוד הגישה (PBKDF2-SHA256).
- המאגר הזה מכיל **קוד בלבד**: אין בו נתונים, קבצים או פרטים אישיים.
- התקנה באייפון: פותחים את האתר ב-Safari ← שיתוף ← "הוסף למסך הבית".
